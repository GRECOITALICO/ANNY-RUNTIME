# ANNY OSS Reuse Policy

## Objective
`required external autonomous agents = 0`

ANNY Runtime must not become a wrapper for Claude Code, OpenCode, OpenHands, Aider, or Codex. 
While we can study their architecture, learn from their patterns, or borrow specific algorithms (subject to strict license compliance), the execution paths must remain ANNY-owned.

## Third Party Additions
Every external library or codebase incorporated into this repository must be strictly audited and recorded in `THIRD-PARTY-COMPONENTS.md`.

Permitted uses of external autonomous agents (only in lab):
- Architecture study
- Benchmarks
- Local comparison tests
